## Размещение и поведение

- Исходники: `/home/operator/workspaces/automation-integrations`.
- Установленная независимая копия пакета, venv, модель и закрытые настройки:
  `/home/operator/.local/share/automation-integrations/greif`.
- STT: faster-whisper 1.2.1 / PyAV 18.1.0, cached small, русский, CPU int8,
  два потока, максимум 120 секунд/32 МиБ. Модель перенесена из SG, не скачана заново.
- TTS: ElevenLabs eleven_v3 с ранее выбранным голосом SG. Ключ перенесён только
  в закрытый файл `secrets/elevenlabs.token`; не в конфигурацию Hermes/argv/git.
- `automation_integrations.hermes_speech`: файловый интерфейс, числовой guard
  в отдельном процессе, приватный WAV, исключительное создание выходного файла.
  Штатный Hermes очищает текст, делит на блоки до 1000 символов и делает Opus.
  Нормализованный блок ограничен 4000 символами; превышение возвращает ошибку.
- Автоответ голосом: `gateway_voice_mode.json`, `telegram:100001=voice_only`.
  Область — весь личный чат Дмитрия, включая темы. Глобальный `voice.auto_tts=false`.
  Распознавание подключено для разрешённых входов Грейфа; существующий allow_from
  не менялся. Обычные текстовые сообщения не запускают автоматический TTS.
- Адресацию, доставку и текстовый fallback выполняет Hermes. Это не перенос
  прежнего dual-reply поведения: короткий текст может быть подписью к голосовому.
  Собственная durable очередь/Runs ingress в этом пилоте не участвует.
