вставок; текст контрактов исходных 55 страниц не изменился, а отличие страницы
«СБИС.ЗаписатьСотрудника» относится к навигации сайта.

## Обнаруженные изменения смысла и ограничения

- `СБИС.ЗаписатьПодразделение` устарел: официальная страница указывает на
  [`sabyDepartment.Update`](https://saby.ru/help/integration/api/all_methods/update_division).
  Новый контракт сохранён в `saby/update_division.html`.
- Основная страница `СБИС.ИнформацияОКонтрагенте` отдаёт оболочку. Связанная
  [официальная статья](https://link.saby.ru/article/885fcb48-f55d-4ab6-a8c4-d7f62a9a73c5/39fd6a6f-dfc1-4559-91aa-49e8563dcd98)
  доступна в веб-индексе, но прямое скачивание вернуло HTTP 307 на SSO. В manifest
  это `failed`, локальный полный текст статьи не заявляется. Статья указывает:
  запрос по реквизитам способен создать отсутствующего контрагента. Поэтому
  название «Информация» не делает этот метод безусловным чтением.
- Новые ссылки Saby включают самостоятельные кадровые и организационные продукты.
  Наличие документации не подтверждает права текущего сервисного приложения.

|---|---|---|

| Yandex Go Business API 2.0 | В скачанных index/quickstart/контрактах отдельный публичный sandbox не указан | Тестовые записи и самостоятельный тестовый токен не подтверждены |

В [песочнице Точки](https://developers.tochka.com/docs/tochka-api/pesochnica) путь
`/uapi/open-banking/v1.0/...` заменяется на `/sandbox/v2/open-banking/v1.0/...`.
Аналогично заменяется только базовый префикс других методов. Официальные фикстуры:
`customerCode=1234567ab`, `accountId=12345810901234567890/044525104`.
Другие идентификаторы следует получать из ответов; таблица страницы не задаёт
конкретный `merchantId`. Песочница формирует ответы платёжных ссылок, но не
подтверждает реальную оплату, переход на платёжную форму или списание.

[Технические требования Saby](https://saby.ru/help/integration/api/techreq_edo)
перечисляют test API ЭДО. Отдельно описан
[платный тестовый аккаунт](https://saby.ru/help/start/test_saby) на
`online.sabytest.ru`, подключаемый менеджером. Его нельзя считать имеющимся
или взаимозаменяемым с `fix-online.sbis.ru` без подтверждения поставщика.

## Воспроизведение

Из корня проекта:

```bash
python3 ops/download_api_docs.py --output docs/api-snapshots/NEW-SNAPSHOT
```

Нужны Python stdlib, curl, существующие pinned SSH-подключения и локальный публичный
корневой сертификат Точки. Рабочие токены не читаются. Используются прежний SOCKS
для ЭТМ, проверяемое имя TLS Яндекса с каноническим Host, pinned root Точки и
штатный SSH SG → Алёна для публичных страниц Saby. Сетевые настройки не меняются.

`--saby-transport direct` позволяет прямой доступ там, где он работает.
`--retry-failed` сохраняет только проверенные хешами успешные загрузки из этого
же снимка и повторяет ошибки; успешные старые файлы из других каталогов не берёт.
Завершение с кодом 1 означает хотя бы одну явно записанную ошибку скачивания.

Проверены SHA-256 всех 200 файлов, уникальность 201 URL попыток, HTTPS-allowlist,
соответствие 52 ссылок Яндекса, число 71 операций Точки и 91 имя Saby.
Бизнес-API этим загрузчиком не вызываются.
