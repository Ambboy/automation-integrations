## Использование

Сначала `integration_catalog(service="tochka")`, затем `view="capabilities"` и точный `capability_id`. Раздел `executable_contracts` содержит схему `path`, `query`, `body`, `headers` для каждого нового имени операции. Старые плоские параметры сохранены.

Пример чтения:

```json
{"service":"etm","operation":"goods_get","params":{"path":{"id":"5301409"},"query":{"type":"etm"}}}
```

Запись: `integration_write(action="prepare", service=..., operation=..., params=...)` создаёт закрытый локальный черновик и возвращает **полный preview**, включая URL назначения. Модель показывает его владельцу. Только новое аутентифицированное личное сообщение `ПОДТВЕРЖДАЮ <draft_id>` подтверждает неизменный запрос; `execute` проверяет его хеш, среду, маршрут и срок 10 минут. `status` возвращает сохранённый исход; существующий специальный workflow такси дополнительно сверяет заказ.

До сетевой записи сохраняются и fsync-файл, и каталог. Неопределённая отправка не повторяется автоматически и не заменяется новым черновиком того же намерения, в том числе на границе истечения срока. Общие операции со статусом `accepted_unverified` приняты API, но требуют отдельной проверки документированным чтением: это не доказательство оплаты, доставки или подписания. Специальный workflow Яндекса сохраняет прежнюю идемпотентность заказа и проверку условий отмены.

PDF сохраняется под `state/artifacts/` с правами 0600; результат содержит путь, размер и SHA-256. Лимит бинарного ответа — 16 МиБ, JSON — 2 МиБ на входе и 60 КБ после очистки. Большие вложения и preview ограничены размерами запросов инструмента; произвольных URL для скачивания нет. Ссылки в ответах провайдера очищаются; это ограничение сохраняется, в частности для подписанных ссылок вложений Saby. Точные URL, которые сам пользователь передаёт в подтверждаемый запрос, в preview видны.

## Установка и откат

Выпуск обновляет только собственные модули/реестры и штатный плагин. `config.yaml` сохраняется побайтно; речь, оформление тем и сетевые туннели не переключаются. Перед применением нужен простой gateway (`active_agents=0`). Исходные байты и SHA целевых файлов сохраняются в private `api-catalog/update-20261004-full-api`.

```bash
PYTHONPATH=. python3 ops/update_catalog_release.py apply --release 20261004-full-api
# Затем штатный idle restart и установленная проверка.
```

Откат:

```bash
PYTHONPATH=. python3 ops/update_catalog_release.py rollback --release 20261004-full-api
```

Откат защищён SHA от перезаписи последующих изменений и требует отдельного idle restart. Состояния неопределённых черновиков и вращающиеся токены Wiren Board не удалять. Позднейшее обновление файлов делает прежние rollback-манифесты неприменимыми без сверки.
