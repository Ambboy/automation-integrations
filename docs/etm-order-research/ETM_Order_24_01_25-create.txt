ETM API. Работа с заказами


     Размещение заказа (Create)
     Метод /invoice/сreate
     Тип метода: POST

     Параметры запроса:
     Наименование поля Тип            Обязательность Описание

     OrderNumber             Number   Да            Номер заказа в системе пользователя

     OrderDate            Date        Нет           Дата заказа
                          (CCYY-
                          MM-DD)
     ExpectedDeliveryDate Date        Нет           Ожидаемая дата поставки
                          (CCYY-                    Данный параметр можно указывать
                          MM-DD)                    построчно товарам (не только на весь
                                                    заказ)
     ContractNumber          Number   Нет           Номер договора

     ContractDate         Date        Нет           Дата договора
                          (CCYY-
                          MM-DD)
     DocumentFunctionCode String      Да            Допустимые значения для заполнения
                                                    параметра:
                                                    P - первичное размещение заказа
                                                    А - подтверждение заказа
                                                    D - отказ по ранее размещенному заказу
                                                    С - изменение ранее размещенного
                                                    заказа
     Remarks                 String   Нет           Примечание к документу



     Buyer: [{                                      Покупатель

     ILN                     Number   Нет           GLN покупателя

     Seller:                                        Продавец

     ILN                     Number   Да            GLN продавца. Указываем константу =
                                                    4660011519999
     CodeByBuyer             Number   Нет           Код покупателя в системе продавца

     DeliveryPoint:                                 Точка доставки
     ILN                     Number   Нет           GLN Грузополучателя (точки доставки)

     Invoicee:                                      Получатель
     ILN:                    Number   Нет           GLN плательщика

     Наименование поля Тип            Обязательность Описание

     Order-Lines: [                                  Данные по товарам

     Order-Lines: [
     LineNumber              Number   Да             Номер строки

     BuyerItemCode           Number   Нет            Код товара клиента, можно использовать
                                                     если загружено сопоставление кодов
                                                     клиента и кодов ЭТМ
     SupplierItemCode        String   Нет            Код товара ЭТМ

     ManufacturerArticle     String   Нет            Артикул производителя

     ManufacturerCod         String   Нет            Код производителя по справочнику
                                                     ЭТМ
     ItemDescription         String   Да             Наименование товара

     OrderedQuantity         Number   Да             Заказанное количество

     UnitOfMeasure           String   Нет            Единица измерения (в соответствии со
                                                     стандартами ОКЕИ)
     OrderedUnitNetPrice     String   Нет            Цена товара без НДС

     OrderedUnitGrossPrice String     Нет            Цена товара с НДС

     NetAmount               String   Нет            Сумма за товар без НДС

     GrossAmount             String   Нет            Сумма за товар с НДС

     TaxRate                 String   Нет            Ставка НДС

     }

     *Примечание: ILN точки доставки можно получить у менеджера.

     Важно: Обязательно должен быть указан один из вариантов: код товара клиента или Код
     ЭТМ или артикул производителя. Артикул производителя обязательно указывать в связке с
     кодом производителя по справочнику ЭТМ, т.к. артикулы разных производителей могут
     совпадать.
     В номере заказа можно использовать:0123456789.-
     ABCDEFGHIJKLMNOPQRSTUVWXYZБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ/
     А- на русском языке не допускается.

     Параметры ответа:
       Наименование поля             Описание
          {
          "status": {
          "code":                    Статус ответа
          "message": ""              Сообщение об ошибке или информационное
          }
     "data": {                       ID заказа
     "id":                           ID заказа в системе ЭТМ
     "ids": [{                       Дополнительный ID

                 "docid":

           }]
          }}
     После получения заказа ваш персональный менеджер обрабатывает заказ: проверяет состав
     заказа, цены, количество и требуемые сроки для возможности поставки.

     Допустимые типы сообщений:

     1. В случае, если в запросе указан артикул производителя (ManufacturerArticle), но нет кода
     производителя (ManufacturerCode), и при обработке запроса в базе ЭТМ найдено более
     одного товара у разных производителей с одним и тем же артикулом, в ответе на запрос в
     параметре "message", будет следующий текст сообщения: «В заказе обнаружена товарная
     позиция, артикул которой обнаружен у различных производителей».
     Отдельная группа параметров «data» с указанием этого артикула/артикулов.

     2. В случае, если в запросе указан артикул производителя (ManufacturerArticle), и в базе
     ЭТМ не найдено ни одного подходящего значения, в ответе на запрос в параметре "message",
     будет следующий текст сообщения: «В заказе обнаружена товарная позиция, артикул
     которой не обнаружен в справочнике ЭТМ с указанием этого артикула.»
     Отдельная группа параметров «data» с указанием этого артикула/артикулов.

     Пример ответа:

     { "status": {

          "code": 400,

       "message": " В заказе обнаружена товарная позиция, артикул которой не обнаружен в
     справочнике ЭТМ"

     },

     Пояснение:

     DocumentFunctionCode = С - система перезаписывает ранее размещенный заказ и все
     согласованные условия по нему c присвоением нового id документа. Изменение заказа
     допустимо для документов в статусе Спецификация или Счет на оплату. Для других статусов
     документов изменение невозможно и при попытке отправки запроса вернется сообщение с
     текстом: "Невозможно изменить данный заказ. Не найден исходный документ."

     Пример запроса:
     POST "http://ipro.etm.ru/api/v1/invoice/create?session-id=100989605817597677591271922223"
     Accept: application/json; charset=utf-8"
     Content-Type: application/json"
